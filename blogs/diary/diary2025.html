    昨天懒得写了，晚上定时干了一套超越数学来着。

    距离考研还有11天

    白天订正昨天写的超越数学，选择错了7个，其中至少3个是因为题没看或者粗心搓掉的，填空也是又一个没看清题导致的错误，直接白白浪费20分，加上去的话已经突破90分了。

    下午写了408模拟卷的大题，这次的算法题是dijkstra找最短路，看来得抽时间去看看这个模板了。

    晚上写了一套英语真题，前面的发挥还是不错的，但可惜最后一篇阅读完全没看懂，错了4个，七选五更是全错，哎，这次就不太行了。

    肖四到货了，晚上写完最后一套八的选择题，拿下21的高分。之后背背大题的第一题，晚上回去自然变晚了。

    # 12-9

    今天晚上要出准考证了，看来得准备一下然后去订酒店。

    白天订正了剩下的超越题，有个狗屎计算算了好久。

    下午写了套肖四，直接拿下26分，之后是408模拟题，只做了选择题，这次错了10个，感觉良好。

    晚上定时写了一套张4，这次选择题错了三个，但是填空只对了2个，大题的情况也不怎么样。

    毛估估倒是有80分，可见大题的情况比较糟糕。

    之后背了背政治。

    # 12-10

    今天白天看了看昨天的张4，订正了后面的题。

    大的问题感觉也不是很多。

    下午写了408模拟题的大题，做的也还可以。然后还写了一套肖四，顺便背会英语单词。

    晚上写了英语真题，这次的英语真题做的很不错，就阅读错了2个，以及完型的9个，其他全对。让我信心大增。

    之后背了近一个小时的肖四。

    # 12-11

    今天白天写了一点超越题，但是没写完。

    下午偷了点懒，没写408，但是稍微看了看知识点，干了一套肖四，明天应该就能刷完了。

    晚上定时干了最后一套张4，选择错了4个，填空俩，大题不清楚，最后一道概率没时间做了，下次不能被浪费太长时间。

    之后背了背肖四。

    # 12-12

    今天白天订正昨天的张四，因为偷懒没能订正完。

    下午继续偷了懒，没写408，写了最后一套肖四，订正了张四。

    晚上写了一套英语真题，这次的阅读错了11个，比较多，这个文章确实比较难，我看不懂啊！

    之后背了背政治

    # 12-14

    昨天懒得写了。

    今天也是考研前的最后一个双休日了，虽然我只是早上多躺一会。

    白天摸了会鱼，数学订正了一点点。

    下午写了最后的408模拟大题，然后看了看之前留下的英语。

    晚上订正英语并总结。之后背了1个多小时的肖四。还是比较难背的。

    # 12-15

    今天虽然摸鱼，但是也复习到了一个知识点。

    下午写了英语大小作文，虽然是照着模版写的，不过练练手，明天也继续练练。

    之后408没做题，随便看了看知识点。

    下午写了一套24数学真题，很可惜，由于不仔细，白送了25分，即便如此，也还能接近90分，至少对于我来说，如果没有粗心错误，那么成绩会比较理想。

    晚上背了1个多小时的政治，好难背啊。

    # 12-16

    距离考试只有4天了，很快就能过去了。

    白天订正了昨天的数学试卷，发现24的大题其实都挺有难度的，或者新类型，要不就是计算量较大，小题反而简单，可惜我因为粗心错了好几个，得改！

    下午写了24年的408真题，已经切实感觉到当年的噩梦了。小题还行，大题个个跟阅读一样， 后面的三大题加起来甚至才6分，情况不太行，不过好在前面做的还可以，选择十个，算法题和应用题全对，计组也是基本可以拿到得分。统计了一下刚好99分。

    明天再好好校对一下，大题是真的难做。

    晚上写了24年的英语，完型错了10个，有点多，阅读基本还可以，但是有一篇错了4个，总共8个错误，七选五错了3个。除了阅读错得多了一点，其实还行？大概有53分左右，不过希望正式考试的时候能再少一点。

    之后又是艰难的背书环节。

    # 12-17

    倒计时三天！

    白天随便看了看超越题。

    下午订正昨天的408真题，这大题实在是有点抽象，不过也是又有几个粗心的错误，如果修正了，那么就直接能够上100了。

    晚上写了一套25的数学，选填各错俩，大题没有全对的，但是也没有全错的，能拿的分拿了，但是算错的分还是比较多，明天再好好看看。

    之后又是背书环节，不过今天的相对比较容易。

    # 12-18

    明天最后一天！

    今天是呆在这的最后一个晚上了。明天就要准备去考场那边的酒店了。

    白天直接开摆了，基本没学。

    下午408真题，25的真题比24的真题简单，选择错了8个，刷新历史最少。大题感觉也不错，这次毛估估100必定上去了。

    晚上英语真题，也是25年的，这次的阅读错的比较多，10个，比24年的还多错俩。文章看不懂很难受啊。

    之后背了背政治。

    终于快结束了。希望如此。

    # 12-19

    今天的白天也是直接开躺，快到中饭点了，才去收拾了一下东西。

    之后准备去车站了，这次是舍友骑着小电驴带我去的地铁站。

    下了高铁以后，也是等待爸妈的接送，有点失策了，感觉不应该坐高铁的，倒不如直接让家里人带我去考场。

    这次订的酒店感觉还挺不错的，智能家居，喊一声就有了，有点意思。

    然后放下东西就和爸妈出门买晚饭吃了。

    在之后洗漱洗漱，然后看了一会肖四，差不多11.，然后准备睡觉。

    # 12-20

    考试的当天，也是被成功叫醒了，早餐是老妈在楼下小摊买的手抓饼。

    之后直接进考场，当然，因为去的太早，不让进。

    稍微继续看了看政治。

    再之后就是进考场了。

    ....

    政治考完了，肖四压到了几个题。也是基本能背出来的。

    自我感觉还行。

    然后在考场旁边吃了顿午饭。

    下午是英语考试，感觉可能这次的英语阅读比较简单？并没有什么难以理解的内容。

    在之后就是返回酒店了。

    # 12-21

    今天是考研的最后一天，早上也是和昨天一样。

    今天的数学，感觉还行，虽然后面对答案的时候错了好多。

    很可惜，我感觉可能无法成功上岸了。

    下午的408又是给我一记沉重打击。大题出的非常恶心。数据结构的算法还行，我至少能写出来，后面的关于栈的问题，是比较抽象的，虽然不至于全错，但是也拿不了多少。计组更是逆天，虽然看着问题难度不大，但是那个电路图，巨抽象，反正我做不了。在之后操作系统的文件系统，太阴了，什么叫删除文件时要对哪些元数据进行什么操作，这道题根本没法下手啊，甚至还占5分。

    哎，考完以后去我住的地方，然后收拾收拾准备回家了。
