    # 1-1

    新的一年到了。

    白天睡大觉，下午爽玩。

    老爸老妈都放假，今天有好吃的。

    # 1-2

    白天睡大觉，下午去老家。

    刷了一下午视频。

    晚上和以前的室友猛攻电视台，虽然白给了好几把，但是最后一把肥肥撤离了。

    # 1-3

    白天睡大觉，晚上吃火锅。

    # 1-4

    白天依然睡大觉，下午去干活了。

    晚上在家楼下吃了顿炒年糕，除了比较咸，味道其实还行，我的嘴巴并不怎么挑剔。

    # 1-5

    今天休息，睡到中午，午饭喷射套餐

    晚上吃好吃的。

    # 1-6

    白天睡大觉，下午去了三个地方。

    晚饭在一户人家那里吃饭。

    被难绷的监控整了两回。

    最后九点才回家。

    # 1-7

    白天睡大觉，下午有点忙，虽然我摸鱼。

    晚饭在附近吃的，吃了38，感觉不如喷射套餐。

    晚上甚至还有夜班，最后8.才回家。

    # 1-9

    昨天和今天差不多。

    晚上吃了喷射套餐。

    不过今天倒是正常下班了。

    # 1-10

    今天赖床一天，下午爽玩。

    晚上记了一点账

    # 1-11

    今天休息，爽玩。

    晚上吃的喷射套餐。

    # 1-12

    白天睡大觉，下午干活。

    晚上回老家吃饭。

    # 1-13

    下午干活，顺便摸鱼。

    晚上吃外卖，这次迫于压力，不能点喷射套餐了。吃了不辣的麻辣香锅。

    # 1-14

    今天休息一部分，中午吃了喷射套餐。

    下午干活，但是又没有完全干，大概下午三点被拉去。

    # 1-15

    今天下午老妈回家没带钥匙，直接提前下班。

    晚上吃好吃的。

    # 1-16

    今天晚上在馒头厂吃饭。

    晚上顺便回了一趟老家，给爷爷冲了花费。

    # 1-17

    今天我星期六，本来休息，下午还是被拉去干活了。

    不过中午吃了一顿喷射套餐。

    晚上老妈叫了她的朋友来家里，吃了顿好的。

    晚上老妈又出去玩了，只能由我搞定卫生。

    # 1-18

    今天直接躺到了下午。

    午饭吃的比较迟。

    晚上吃了喷射套餐，还得是喷射套餐，巨香，虽然一直吃可能对身体不好。

    # 1-19

    白天睡大觉，下午干活。

    晚上吃的有点勉强，老爸烧的奇怪的料理，能吃。

    # 1-20

    今天雨夹雪，有点冷，没去干活。

    下午玩，晚上和老爸整了个小火锅吃。

    # 1-21

    距离考研结束已经一个月了。

    今天更冷了，下午去干活，但是又没完全干

    晚上回老家，老爸修电灯还有开关。之后吃了炒年糕。

    # 1-22

    今天去学校吃午饭，结果变成最后一顿了，之后再也不能蹭了。

    下午玩，晚上吃了疯狂kfc，爽吃。

    # 1-23

    白天睡大觉，下午玩，午饭吃了昨天剩下的kfc。

    晚饭烤了年糕吃，酱油放少了，有点淡

    # 1-24

    白天睡大觉，晚上被拉去干活，虽然基本没干。

    晚上整理账本，整了俩小时。

    # 1-25

    今天睡到了下午4.，午饭都没吃，直接吃了晚饭。

    # 1-26

    今天起的比昨天稍微早一点，

    晚饭烤了年糕吃。楼上修卫生间，给我家干漏了。

    # 1-27

    今天又比昨天早起一点。

    中午吃饭。

    晚上吃塔斯汀。

    # 1-28

    睡大觉，老妈晚上回家做菜，直接吃好吃的。

    # 1-29

    睡大觉，下午回了趟老家，之后被拉去干活了。

    # 1-30

    下午被叫去办事，晚上正常吃饭

    # 1-31

    中午居然准时吃饭了。晚上吃了喷射套餐，由于下雨天，500m硬是送了1个小时，而且还没点准时宝

    # 2-1

    今天继续懒觉。

    晚上吃了炸坤。

    # 2-2

    下午去办事，晚上吃了喷射套餐。

    下单了一个空气炸锅，还有40个手抓饼面皮，之后应该会买蛋挞皮吧

    # 2-3

    下午办事，昨天买的空气炸锅和手抓饼到货了。速度还是非常快的，立马下单了一箱蛋挞皮。

    # 2-4

    下午的事还没办完，晚上考了蛋挞吃。味道确实一样。

    # 2-5

    今天中午去老家了一趟，为了办事，结果下午还是没能办成功，这破玩意怎么这么难搞，系统的信息同步问题有点难绷，哎，索性下个礼拜再整，之后应该没什么大事了。

    # 2-6

    今天睡大觉，中午吃了烤年糕，老爸烤的，鸡蛋很咸。

    晚上吃了煮年糕，也是老爸烧的，这次味道还可以。

    晚上顺便学习了一下算法，正在试图理解二分，感觉也挺难的。

    # 2-7

    偷懒没学习。

    # 2-8

    今天学习了二分，关于边界问题的讨论是一个难点。还需要花点时间才能解决。

    中午吃了一个老爸从家里带回的粽子。

    晚上吃了老板烧的菜，味道感觉还行

    晚上和朋友打游戏.

    # 2-9

    今天也是没学。

    晚上吃了大餐。爽吃

    # 2-10

    下午收拾收拾回老家，明天准备去外婆家

    # 2-11

    大早上就被叫起来了，开了一下午车，这六百km基本都是我开的。

    路上服务区买了个鸡排吃，之后又是一个鸭腿。

    这次路上堵车情况并不严重，也是在下午5.的时候到达了目的地。

    晚上吃席，虽然我已经差不多吃饱了。

    # 2-12

    今天早上被叫起来吃早饭，但是我又睡过去了，醒过来就中午了。

    中午还是一样的吃席，下午玩了手机、平板什么的、晚上吃了7层高的蛋糕、

    之后就是开玩了。

    # 2-13

    醒来已经中午了。在外婆家吃午饭，下午继续玩，二哥下午也差不多到了。

    晚上照样吃饭。吃完回去玩。

    比较奇怪的是，房间里的灯突然坏了，然后坐车去镇上买灯泡，顺便加一个插排。

    大晚上，二哥出门吃烧烤去了，当然我没好意思去。

    # 2-14

    睡到中午，中午炫炒饭，下午开车带二哥去市区医院看望他的爷爷。

    晚上吃好吃的。之后又是直接开玩

    # 2-15

    睡到了中午，今天是真的热啊，下午去摘了草莓，四姨请，带了一堆小孩过去，摘了680的草莓。

    晚上和二哥玩了会网上的街机小游戏，然后没多久他就要去照顾爷爷了。

    # 2-16

    今天是除夕，午饭吃了一顿好的，晚饭也是，二哥在医院照顾了他的爷爷一整天。

    只好稍微炫耀一下午饭和晚饭吃的啥了。

    傍晚和舅舅开了俩把王者，一输一赢。

    也是第一次在外婆家的村子里跨年，这里居然没人放鞭炮，我记得前年是二哥带我去县城里放鞭炮来着，那里倒是挺热闹。

    夜晚静悄悄的，无事发生。

    # 2-17

    今天是正月初一，午饭和晚饭都在二姨家吃，下午和舅舅二哥去了山上挖东西。

    在之后去了一趟附近的景区，有个滑道20块一个人，感觉不太行，没啥感觉。

    之后倒是没啥活动了。

    # 2-18

    今天初二，去走亲戚了，蹭了一顿午饭。

    下午没去活动，天气太冷了。

    晚上还是在家吃。

    # 2-19

    今天没啥活动，刷了一天的视频

    # 2-20

    今天去大姨家吃饭，中午也是很不情愿地被叫起来了。

    下午跟着去采了点药草，我倒是在旁边摸鱼。

    晚上也在大姨家吃饭，之后就是回家了。

    # 2-21

    今天是初五，去了四姨家吃饭。拜年这个也是要进入到尾声了。

    早上还没到九点就被叫醒了，根本睁不开眼睛。之后继续赖着，等差不多11点了才起来。

    吃完午饭，刷了一下午的手机，晚上倒是也没啥好说的。

    明天一大早就得起床，今天估计不用睡觉了。

    # 2-22

    今天一大早就起来了，吃了早餐，然后告别之后就出发回家了。

    刚开始还好点，之后就是大堵车，堵了好久，去了四次服务区，每个服务区都爆满。

    最后在晚上11.30开到了老家。

    倒头就是睡。

    # 2-23

    直接睡到了大中午。吃完饭陪老妹出去放鞭炮。

    之后也没什么特别的了。

    # 2-24

    据说是今天考研出成绩的，但是好像没啥动静，应该说并没有出？

    不过应该也快了。

    晚上去亲戚家吃饭，这次吃的大餐。

    其他倒是也没啥值得注意的。

    # 2-25

    今天没什么特别的。

    吃完午饭就开始玩了，稍微改了改自己的博客，但是打包遇到了问题，目前解决不了。

    # 2-26

    据说28号出成绩，应该是确定了。

    中午吃完饭就开始玩了，玩了一个下午。

    晚上也是。今天下的雨还是比较大的。

    # 2-27

    下午从老家回来了，晚上吃了好吃的。

    把之前千问送的-25优惠券花了，买了三杯蜜雪冰城，花了4.8

    # 2-28

    今天出了考研成绩，比估计的还低，操。

    一志愿是上不了了，好在过了国家线，还是有机会调剂的。

    早上也是被朋友的电话叫醒了，催我看成绩，结果令人失望，看来我的水平真的不太行。

    明明都学了这么久了，哎。可能是方法不对吧。先不管了，等着调剂吧，有个书能读就行。

    晚上爸妈去外面玩，还带回来一个榴莲披萨。

    # 3-1

    新的一个月了。

    今天醒过来就下午了，明天得睡的稍微早点。

    晚上吃了喷射套餐。

    没有什么特别的

    # 3-2

    今天醒的挺早，差不多九点就醒来了。

    但是躺到了下午，下午去银行办事，也是终于办成功了。

    最近也是越来越焦虑了，想到我这b分，基本没啥学校能读，甚至连本专业都不一定有。

    哎，要是能再多点分就好了。

    真的难受啊，现在啥也不求了，有个书能读就行了，不然在家里是真的没法混了。

    万一真的没得读，那我该去四战吗？真的太亏了。希望调剂能上吧，来什么都行。

    # 3-3

    好焦虑啊，这段时间经常失眠，该怎么办呢。

    就算调剂上岸了，学校也不会怎么样，我与那些早就上岸的或者早就上班的同学相比，没有任何的优势，学校不行，工作经验也没有，哎。

    目前最好的打算就是调剂上岸，这样起码是个研究生了，可是对未来来说，找工作又会陷入本科毕业的那种情形，该如何是好。

    如果打算四战，还要再花费一年的时间，成本实在是太大了。万一又再次失败了，这辈子感觉都不好过了。

    真的没法了。先看着吧，调剂能上就上，怪我学的一坨以及那盲目的自信。

    # 3-4

    今天又是难受的一天。

    中午烤了俩手抓饼，下午玩了一会。

    晚上吃了顿泡面，出门采购了一波物资。

    在之后就是拿空气炸锅烤了几个香肠。

    # 3-5

    今天又是挨骂的一天。

    打算明天学点生活技能，先试试做饭。

    中午吃了泡面，晚上吃了手抓饼，这样下去确实不是办法。

    看我能烧成什么样吧。能吃那种就行。

    # 3-6

    今天打算做饭来着，中午吃了泡面，晚上没机会烧，老妈回家弄了个披萨吃。

    无他。

    # 3-7

    今天中午尝试了蛋炒饭，感觉还行，除了配料有点少，下次多加点。

    可以加点豌豆进去，或者是香肠。

    晚上去了表妹那里，看看热水器，最后发现没交电费导致的热水器没热水。

    # 3-8

    今天是妇女节，老爸老妈晚上出门买东西去了，好像弄了个金手串。普通珠子加一个金子花的那种。

    中午吃的泡面，晚上吃的好吃的。

    # 3-9

    今天也没啥特别的。

    中午吃了泡面，晚上炒了碗炒饭，感觉还可以，明天去超市买点料。

    下午出门拿了个快递

    # 3-10

    做了一个很长的梦，梦到开坦克，耍盾斧超解等等。

    中午吃了泡面。晚上吃了米饭，菜是昨天剩下的。

    晚上给老爸下单了材料，不过立马结清了。

    之后思考了一会生活，对未来也是迷茫。

    对了，明天还得去趟超市呢，我想想，应该买点豌豆用来炒饭，等炒饭做的熟练了，可以试试别的了。

    # 3-11

    中午吃完泡面，下午被拉去干了一小会活。

    给一户人家装一个巨难装的水晶灯，超重，接线还麻烦，藏线的盒子还小，卡了好几次才装进去。

    装完他妈的还不会亮了。这个是晚上才知道的，因为测试的时候明明是好的。

    之后去亲戚家接摄像头，听说菜地里经常有人偷菜，这才去装的摄像头。

    晚上在包子厂吃晚饭。

    在之后就是回家了。

    # 3-12

    今天中午吃的泡面，晚上吃了我炒的炒饭，超市还没去过，料不多。

    下午本来打算去昨天水晶灯那里的，最后也没去。

    拿了俩快递，其他也没啥了。

    # 3-13

    中午又吃了泡面，下午去了修水晶灯，发现只是电线连接处烧糊了，重新接一下就完事了。

    晚上吃了个手抓饼，想着加一个火腿的，结果不小心滑到地上去了，手抓饼还烤糊了。

    操。

    # 3-14

    今天是星期六，老妈今天也休息。

    中午吃了一个粽子，晚上吃了好吃的。

    其他倒也没啥了。

    # 3-15

    中午吃了好吃的，老妈弄了个披萨。

    玩了一下午。

    晚上也是吃好吃的，虽然老妈烧的土豆丝很赞。

    # 3-16

    今天下午出门采购了一波物资。

    拿了个快递。

    晚上吃昨天老妈做的菜。

    # 3-17

    今天也没干啥事。

    中午吃了泡面，晚上炒了炒饭，今天多加了点东西。

    下次对调料方面稍微改进改进。

    # 3-18

    今天也是不知道干什么的一天。

    中午泡面，晚上老爸从外面带了菜回来。

    # 3-19

    一样没啥。

    中午吃了泡面，晚上老爸烤了年糕吃。

    稍微焦虑了一会，但是又不知道干点啥。
